# Industry presets

Starting points, not answers. The brief overrides any of this. Use a preset to propose defaults in step 2 and 3, then adjust.

## Fintech and banking

- Mode: unified, Apple flavor on iOS, Material on Android
- Density: comfortable for consumer, compact for trading and accounting
- Palette mood: restrained, one confident primary (deep blue, teal, green or an unexpected warm hue to stand out), strong neutral ramp. Gains and losses: do not rely on red and green alone, add arrows and signs
- Type: precise sans (Inter, Geist, IBM Plex), tabular numbers everywhere, mono for account numbers
- Trust: show security status, confirm before money moves, undo where possible, plain language fees, no dark patterns
- Compliance: disclosures readable (not 10px gray), session timeout warnings

## Health and wellness

- Mode: unified, soft shape personality
- Palette mood: calm, warm neutrals, avoid clinical cold blue unless it is a clinical tool; error color still clear
- Type: humanist and highly legible (Atkinson Hyperlegible Next, Source Sans 3, Nunito Sans), base 17 to 18
- Trust: privacy explained in plain words, sensitive data hidden by default on shared screens
- Accessibility: AAA contrast for key text, larger targets, avoid time pressure
- Compliance: HIPAA, GDPR consent flows

## E-commerce and retail

- Mode: unified or Polaris patterns for the merchant admin
- Density: comfortable, image led
- Palette mood: let product photos carry color, UI mostly neutral, one strong action color for Add to cart and Checkout
- Type: brand display face for headings, clear sans for prices and details
- Patterns: fast search, filters as chips and sheets, sticky add to cart on mobile, guest checkout, clear delivery dates, reviews summary
- Performance: images optimised, LCP under 2.5s

## SaaS and dashboards

- Mode: modern web flavor or Carbon for data heavy enterprise
- Density: compact option, tables over cards
- Palette mood: neutral ramp doing most of the work, primary for actions only, data palette separate from brand
- Type: Inter, Geist or Plex, 14 body in app, tabular numbers
- Patterns: sidebar navigation, command menu, saved views, bulk actions, keyboard shortcuts, empty states that teach
- Companions: `dataviz` for every chart

## Game

- Mode: custom, built from the game's art direction; core rules still apply for menus, settings, store
- Palette mood: from the game world; HUD needs contrast against any background (outline or plate behind text)
- Type: display face with character for titles, very legible face for HUD and settings
- Patterns: controller and keyboard navigation with clear focus, safe area for TV, large subtitles option, colorblind modes, remappable controls
- Companions: SpriteShip connector for UI packs, `anatomy` or `hairline-create` for marketing pages

## Kids and education

- Mode: unified, soft or pill shape personality
- Palette mood: bright but not neon, one color per subject or area for wayfinding, keep contrast
- Type: rounded and very legible (Nunito, Andika, Lexend), large base (18 to 20)
- Patterns: huge targets (56+), audio and icon support for non readers, no ads or manipulative streaks, parent area behind a gate
- Compliance: COPPA, GDPR-K, no tracking by default

## Portfolio and creative

- Mode: custom, expressive type set
- Palette mood: minimal UI so the work leads; or one bold brand color owned completely
- Type: a distinctive display face (Fraunces, Clash Display, Instrument Serif, Bricolage Grotesque) with a quiet body
- Patterns: work first, fast image loading, case studies with real process, contact in one click
- Signature detail is essential here: a cursor, a transition, a layout grid break

## Local business (restaurant, salon, bakery, clinic)

- Mode: unified, warm
- Palette mood: from the place itself (signage, interior, product), photos of the real place and products
- Type: characterful display for the name and headings, plain sans for hours, menu and prices
- Patterns: hours, location, phone and booking above the fold on mobile, menu as real text not PDF, map link, reviews summary
- Performance: works well on slow mobile

## AI product

- Mode: unified, `gemini-ai-visual-design` for AI specific surfaces if installed
- Palette mood: avoid the default purple gradient; pick a seed that fits the product's job
- Type: clear sans, mono for model output that is code or data
- Patterns: streaming output with stable layout, stop button, clear sources and citations, edit and retry, show what the AI can and cannot do, human handoff
- Trust: label AI generated content, show uncertainty, easy feedback on answers
